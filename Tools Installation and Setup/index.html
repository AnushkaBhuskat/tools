Tool 05

Google Apps Script: Creating Google Forms Guide

Automate Google Forms creation programmatically using Apps Script.

🌐 Step 1: Open Apps Script

  1. Go to script.google.com.
  2. Click + New project.
  3. Replace default code with the form script on the right.

▶️ Step 2: Run & Get Form URL

  1. Click ▶ Run button.
  2. Click Review Permissions → Allow.
  3. Check the Execution Log to view your new Form URL!

💻 Step 3: Google Form Script Code

function createKrishKalpForm() {
  // 1. Create Google Form
  const form = FormApp.create("KrishKalp Feedback Form");
  form.setDescription("Created via Apps Script.");

  // 2. Add Questions
  form.addTextItem()
      .setTitle("What is your Full Name?")
      .setRequired(true);

  form.addMultipleChoiceItem()
      .setTitle("Select your Department")
      .setChoiceValues(["Software Engineering", "Data Science"])
      .setRequired(true);

  // 3. Log Output URL
  Logger.log("Form URL: " + form.getPublishedUrl());
}

🔍 Why Developers Need Analytics

  • User Traffic Tracking: See live active users, top pages visited, and traffic sources.
  • Event & Conversion Tracking: Measure button clicks, form submissions, and sign-ups.
  • Performance Insights: Identify broken pages, bounce rates, and mobile vs desktop usage.

🌐 Main GA4 Metrics to Know

Active Users & Sessions

Count of unique visitors and total user interaction sessions.

Custom Events

Triggered when users click specific buttons (e.g. `button_click_submit`).

💻 Basic GA4 Website Integration Code

Include this script tag inside your HTML <head> to start tracking:
